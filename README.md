# 道教净明宗 日历一览 PWA 部署说明

## 📦 项目结构

```
pwa-jingming/
├── index.html          # 主页面
├── manifest.json       # PWA配置文件
├── sw.js               # Service Worker（离线缓存）
├── js/
│   ├── app.js          # 应用逻辑
│   └── data.js         # 数据文件（58日程+73神仙+术语+经典+名胜）
├── icons/
│   ├── icon-192.png    # 应用图标192x192
│   └── icon-512.png    # 应用图标512x512
└── README.md           # 本说明文档
```

## 🚀 部署方法（三选一）

### 方法一：Netlify 拖拽部署（最简单，推荐）

1. 打开 https://app.netlify.com/drop
2. 把整个 `pwa-jingming` 文件夹拖到网页上
3. 等待几秒，自动生成URL（类似 `https://xxx.netlify.app`）
4. 完成！可以直接访问

**优点**：不需要注册账号，30秒完成，自动HTTPS
**注意**：未注册的站点7天后可能被删除，建议注册免费账号长期保存

### 方法二：GitHub Pages（最稳定，推荐长期使用）

1. 注册GitHub账号（免费）：https://github.com
2. 创建新仓库（New Repository），名称随意（如 `jingming-calendar`）
3. 上传所有文件到仓库
4. 进入仓库 Settings → Pages
5. Source 选择 `main` 分支，根目录 `/`，点击 Save
6. 等待1-2分钟，获得URL：`https://你的用户名.github.io/jingming-calendar/`

**优点**：完全免费、稳定、无限流量、自定义域名
**缺点**：需要GitHub账号，首次设置稍复杂

### 方法三：Vercel 部署

1. 打开 https://vercel.com，用GitHub账号登录
2. 点击 "Add New Project"
3. 导入GitHub仓库，或直接上传文件夹
4. 点击 Deploy，等待完成
5. 获得URL：`https://xxx.vercel.app`

**优点**：部署快、自动HTTPS、预览功能
**缺点**：免费版有流量限制（每月100GB，足够个人使用）

## 📱 手机安装方法

部署完成后，用手机浏览器打开URL：

### iPhone（Safari）
1. 用Safari打开部署后的URL
2. 点击底部分享按钮（方框+向上箭头）
3. 选择"添加到主屏幕"
4. 点击"添加"
5. 桌面会出现紫色"净明宗日历"图标，点击全屏打开

### Android（Chrome）
1. 用Chrome打开部署后的URL
2. 点击右上角菜单（三个点）
3. 选择"添加到主屏幕"或"安装应用"
4. 点击"添加"或"安装"
5. 桌面会出现应用图标

## ✨ 功能特性

- 📅 **日历概览**：58个道教日程，月份切换，点击查看详情
- 🏛️ **神仙体系**：73位道教神仙，搜索+分类筛选，点击查看详情
- 📖 **道教练语**：54个常用术语，搜索+分类筛选
- 📜 **经典导读**：道教经典学习路径
- ⛩️ **名胜古迹**：道教宫观巡礼指南
- 📋 **详细指南**：58个日程完整说明
- 🏠 **首页**：今日宜忌、快速入口、净明教旨
- 💾 **离线可用**：Service Worker缓存，没网也能看
- 📱 **PWA安装**：添加到主屏幕，和APP一样体验

## 🔄 更新方法

修改文件后，重新上传到托管平台即可。用户打开应用时会自动检测更新并提示。

## 📝 注意事项

1. PWA需要HTTPS环境才能正常工作（以上三个平台都自动提供HTTPS）
2. 首次打开需要联网加载，之后可以离线使用
3. 图标可以替换为自己设计的图标，替换 `icons/` 目录下的文件即可
4. 数据都在 `js/data.js` 中，可以直接编辑修改
